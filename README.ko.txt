SC4 Shot Collector 1.2.0

SC4 2188 (D3:71:43:B6:CC:0C)의 실시간 샷을 Mac에 누적 저장하고 공의 비행을 재생하는 앱입니다.
실행 파일: dist/SC4 Shot Collector.app
지원 환경: Apple Silicon Mac, macOS 13 이상

사용 방법
1. SC4 전원을 켜고 Mac 가까이에 둡니다. 다른 휴대폰이 기기를 사용 중이면 연결을 해제합니다.
2. 앱을 실행하고 macOS가 요청하는 Bluetooth 접근 권한을 허용합니다.
3. 앱이 SC4에 연결하면 새 샷을 수신 대기합니다. 필요하면 '기기 연결'을 누릅니다.
4. SC4에서 샷을 측정하면 조각 패킷을 모아 샷 표와 저장 파일에 추가합니다.
5. 표에서 샷을 선택하고 '비행 시뮬레이션'을 누릅니다. 선택하지 않으면 가장 최근 샷을 재생합니다.
6. 표 위의 내보내기 메뉴에서 CSV 또는 JSON으로 저장할 수 있습니다.

언어·단위·추가 측정값 (1.1)
- 우측 상단의 언어 메뉴에서 한국어 또는 English를 선택합니다. 앱을 다시 실행해도 선택이 유지됩니다.
- m / yd 버튼은 캐리·총 거리·최고 높이(Apex), 시뮬레이션의 거리·높이·눈금에 함께 적용됩니다. 속도 단위는 원래 단위를 유지합니다.
- 언어와 거리 단위는 시뮬레이션 화면 상단에서도 바꿀 수 있습니다.
- 표와 시뮬레이션에 출발 방향(Launch Direction), 스매시 팩터(Smash Factor), 최고 높이(Apex)가 표시됩니다.
- 출발 방향은 실시간 5번 조각의 각도 필드 또는 이미 저장한 이력의 해당 필드에서 해석합니다. 해석할 수 없는 값은 빈 값으로 남깁니다.
- 스매시 팩터는 볼 속도 ÷ 클럽 속도로 계산하며, 내보낸 파일의 smashFactorSource/smash_factor_source에 계산 출처를 표시합니다.
- 이전 버전으로 받은 기록도 저장한 원본 바이트로 보완해 표시합니다. shots.jsonl은 다시 쓰거나 변환하지 않습니다.
- CSV·JSON 내보내기는 현재 선택한 m/yd 단위를 사용하고, 새 측정 항목도 포함합니다. 원본 패킷·ID·중복 판별 기준은 유지됩니다.
- 언어 파일: Resources/ko.lproj/Localizable.strings, Resources/en.lproj/Localizable.strings
- Bluetooth 권한 설명도 각 언어의 InfoPlist.strings로 분리했습니다.

비행 시뮬레이션
- 3D 시점에서 바닥을 마우스로 누른 채 드래그하면 좌우로 회전하고 위아래 각도를 바꿀 수 있습니다. '시점 초기화'로 기본 각도로 돌아갑니다.
- 측면·위에서 시점은 고정되어 있으며, 3D로 돌아오면 조절한 각도가 유지됩니다. 시점 변경은 샷 값이나 재생 위치를 바꾸지 않습니다.
- 저장된 샷 선택, 재생·일시정지, 처음부터 재생, 시간 이동, 0.25~2배속을 지원합니다.
- 3D 시점·측면·위에서 시점으로 전환할 수 있습니다. '새 샷 자동 재생'을 켜면 수신된 새 샷을 재생합니다.
- 기록된 캐리·최고 높이와 유효 발사각에 궤적을 맞춥니다. 방향 값이 있으면 출발 방향에도 반영합니다.
- 비행 시간과 구름 시간은 추정값입니다. 공기저항·바람·스핀에 의한 휨은 계산하지 않는 기록 기반 시각화입니다.
- 값이 부족한 샷은 추정 항목을 표시합니다. 가정 발사각 조절은 화면에만 적용하며 원본 샷에 저장하지 않습니다.
- 샷 재생과 원본 바이트 보존은 별도 로컬 검증을 수행했습니다. 저장소의 테스트 픽스처는 합성 데이터입니다.

기록 보존 방식
- 기기 삭제 명령(0x44), 업로드 완료/동기화(0x68), 설정·시각·기기 ID 변경, 펌웨어 명령을 보내는 기능이 없습니다.
- 실제 송신 지점의 허용 목록은 기기 정보 조회(0x64), 실시간 샷 조각 수신 확인(0x73)으로 제한됩니다.
- 기기 과거 기록 조회(0x72)는 차단했습니다. 이전 버전에서 이력 수신 후 기기의 저장 샷 개수가 68개에서 0개로 줄었습니다. 명시적인 삭제 명령 없이도 조회가 저장 대기열을 소모할 수 있으므로 해당 기능을 제거했습니다. 기기 내부 플래시 삭제 여부까지 확인된 것은 아닙니다.
- 이미 받은 샷은 Mac에 남아 있습니다. 이 업데이트는 기기 기록을 복원하지 않으며, 실시간 수신 확인이 기기 내부 기록 유지에 미치는 영향은 별도 확인이 필요합니다.
- 앱에는 삭제·초기화 버튼이 없습니다. 연결을 해제하거나 앱을 다시 실행해도 기존 샷 파일을 지우지 않습니다.
- shots.jsonl은 O_APPEND로만 열고, 중복 기록은 기기·기록 ID·샷 시각으로 판별합니다. 측정값이 같다는 이유로 서로 다른 샷을 합치지 않습니다.
- 손상된 마지막 줄도 원본 바이트를 남깁니다. 새로운 기록은 별도의 줄에 추가합니다.
- 수신 원본을 디스크에 기록한 뒤 다음 샷 조각을 요청합니다. 마지막 조각 확인은 완성된 샷이 저장된 뒤에만 보냅니다.
- 기기 정보와 설정 메시지는 샷 표에 추가하지 않습니다. 해석할 수 없는 값은 추정치로 채우지 않습니다.

확인된 내용과 검증 범위
- 실제 SC4 2188에서 BLE 서비스/수신 채널 연결, 알림 구독, 기기 정보 조회를 확인했습니다.
- 기기 정보 원본: 536401008603fa000b0000000500006e000c45f6
- 이 초기 응답의 저장 샷 개수는 0개입니다. 빈 대기열의 조회 전후 값이 같았던 것만으로 기록 보존을 검증할 수 없었습니다.
- 원본 MySwingCaddie 3.7.0의 REA 메타데이터와 해당 코드 구간의 정적 분석으로 조회/삭제 명령 및 샷 필드 순서를 확인했습니다.
- 이후 비어 있지 않은 이력 68개를 실제 수신했습니다. 수신 전후 기기 개수가 68→0으로 바뀐 것이 확인되어 이력 조회를 차단했습니다. 수신된 파일과 오프라인 이력 해석 코드는 보존합니다.
- 이력 67/80바이트 형식은 공식 앱의 정적 직렬화 구조를 근거로 지원합니다. 다른 형식은 원본을 보존하고 임의의 샷 값을 생성하지 않습니다.
- 현재 기기는 PIN 교환 없이 기기 정보 조회에 응답했습니다. 확인되지 않은 PIN 명령을 대신 보내거나 기기 ID를 바꾸지 않습니다.
